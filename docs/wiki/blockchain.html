抵押品看似足够，Aave 借款为何失败；利息和价格怎样改变风险？智能合约、Aave 阅读路线V3 借款、利息与健康因子本地供借、风险失败与清算

怎样读一篇源码样板​

  1. 基础：先确认账户、资产、单位和动作参与者。以太坊合约和 Solana 程序的账户模型不同；主账户、子账户、vault 与签名代理也不能混用。
  2. 机制：阅读主文的状态表和图，区分请求、校验、状态提交与异步通知；把输入输出和取整方向写成可核对的数值。
  3. 源码：沿主文的固定提交链接检查实际函数和调用关系。版本是各篇核查时的基线；升级后需要重新核对，不能把包版本当作当前部署证明。
  4. 实验：从上表进入各篇实验节，先读环境与范围，再下载原脚本、锁、输入和原始输出，在隔离目录复现。未执行的后续实验会单独标明。

Solana、Uniswap V3、Aave V3、Drift、Hyperliquid 五篇已完成作者以外的技术复核；Ethereum/Reth 与 Lightning 为新增，证据边界见各自主文。下面列出证据范围，具体版本、日期、命令和失败分支保留在各主文中，避免导读复制后失去同步。

每种证据能回答什么​

样板已有证据阅读时保留的边界
Solana固定 Agave/Yellowstone/Geyser 接口源码与公共 Devnet 只读 RPC 记录未运行配套节点和插件；RPC 样本不证明网络部署了所读稳定提交
Ethereum / Reth固定 v2.11.0 源码、官方测试运行（交易池 nonce、执行器状态、Berlin 创建合约）未启动整节点/连接共识层/同步主网；源码版本不等于公共节点部署
Uniswap V3固定 core/periphery 源码、本地池 EVM 成功/失败与独立数值复算Router 仅源码核查，未部署集成；不是主网或 fork 验证
Aave V3固定本地实现、真实逻辑库、本地借款/计息/风险失败和清算代币、预言机和管理员使用 Mock/EOA 夹具，不证明生产治理、喂价或当前主网参数
Drift原生 Rust 函数、状态与原始事件、独立数值校验五个独立夹具不是同账户连续交易；函数返回 Err 不证明交易原子回滚；20 quote 抵押是明确假设
Hyperliquid公开 SDK 源码、真实离线签名、合成事件对账与公共只读样本不证明服务端接受签名或真实 WS 故障恢复；未取得可审计 HyperCore 撮合/共识/风险引擎源码
Lightning固定 LND v0.21.8-beta 源码、51 项源码断言、shachain 运行实验未执行 regtest 违约演练与 watchtower 端到端；不是审计报告

共享术语帮助提出同一组问题，具体保证金、利息、资金费、清算和确认规则仍以各协议、各版本为准。不能把某个本地测试通过推广成整个协议、当前部署或任意输入均已验证。
