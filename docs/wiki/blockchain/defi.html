DeFi

同样是一次用户操作，Swap 改变池与代币余额，借款增加债务并检查账户风险，永续成交则改变仓位和费用记账。先明确要核对哪类状态，再选择专题。

阅读目标前置与导读源码主文实验
交易价格、跨 tick 与付款结算智能合约、Uniswap 版本路线Uniswap V3 Swap本地 EVM 与回调失败
债务、利息与健康因子Aave 阅读路线Aave V3 借款与风险本地借款、风险失败与清算
成交、资金费与仓位风险永续合约术语、Solana 账户基础Drift 仓位生命周期原生 Rust 与事件复算

Aave 的借贷健康因子与永续合约保证金各有自己的账户与估值规则；Drift 的风险函数不能直接用于 Hyperliquid。需要研究签名、订单未知结果与连接恢复时，从 Hyperliquid 进入 SDK 与合成对账样板。

各篇提供固定版本、实际实验和未测边界，导读不将本地实现推广为当前生产部署。返回区块链总导读选择其他问题。
