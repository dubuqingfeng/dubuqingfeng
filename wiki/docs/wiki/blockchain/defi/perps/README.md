title: 永续合约：仓位、保证金与结算
---

永续仓位没有固定到期日，但持续受到价格、费用、资金费和保证金约束。阅读时先分开四个问题：**谁提供成交价格，谁承担库存，谁验证风险，谁承担无法收回的亏损**。订单簿、AMM、LP 与保险基金分别回答不同问题，可以同时存在。

- **订单与成交**：接受订单表示系统保存了交易意图；只有实际 fill 才改变已成交仓位。部分成交、过期、撤单、条件未触发须分别处理。
- **仓位与盈亏**：有符号数量乘估值价格，加上有符号的报价资产记账额，得到该记账口径的盈亏。成交价、估值价、退出可成交价不同；费用和已结资金费是否包含其中由实现决定。
- **初始保证金与维持保证金**：前者约束增险操作，后者约束仓位存续；挂单可能占用风险额度。全仓汇总账户，逐仓限制某个仓位的抵押范围；不同协议的子账户、隔离与逐仓并不自动等价。
- **资金费**：持仓双方或池子之间的周期性转移机制，用于约束永续价格偏离。累计费率更新、个人结算、实际资产提取是不同动作，正负号、周期、上限和不平衡补贴须查协议。
- **清算与破产**：先判断风险是否不足，再按协议规则减仓、转移仓位或资产。仓位归零后可能仍有负余额；保险与社会化损失属于后续亏损处置。不要把保险写成兜底承诺，也不要把某协议的 ADL 推广成永续合约必备机制。

从[Drift 仓位生命周期](./drift-position-lifecycle.md)进入固定源码、费用/资金费计算、原始 Rust 成交与风险实验。它将上述概念映射到 Drift v2.161.0 的具体账户与函数。后续协议可引用本页术语，再给出各自精度、风险模型和结算规则。
